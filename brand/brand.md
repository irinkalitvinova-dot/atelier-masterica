# Бренд: ателье «Мастерица» – пошив и ремонт одежды (вымышленное, демо)

Идея: сантиметровая лента. Это единственный яркий приём сайта: жёлтая лента с делениями бежит по левому краю страницы, а по ней видно «сантиметры» прокрутки. Всё остальное спокойное.

## Цвета
| Название | Код | Где |
|---|---|---|
| Синий (шерсть) | #1D3A6B | заголовки, тёмные блоки |
| Текст синий | #2B3F66 | основной текст, линии (чёрного нет, он для мужских сайтов) |
| Небо (фон) | #DFEBF6 | фон страницы, голубоватый |
| Мел | #F6FAFD | светлые блоки |
| Лента | #F4C430 | сантиметровая лента, кнопка |
| Булавка | #C8362F | один маленький акцент (булавка, ошибка) |

## Шрифты
- Заголовки: Prata (с засечками, строгий, есть кириллица)
- Текст: Golos Text (спокойный гротеск, есть кириллица)

## Правила
- Яркий жёлтый – только лента и главная кнопка.
- Красный – только булавка.
- Текст выравниваем по левому краю.
- Тире короткое «–».
- Сайт демонстрационный: адрес, телефон и цены вымышленные.
